## ✨ 游戏特色

### 🌟 核心玩法
- **经典规则**：卧底 vs 平民，谁先找出对方？
- **多人对战**：支持 6-12 人同时参与
- **词语丰富**：内置 44+ 组词对，涵盖食物、动物、职业等 7 大主题
- **随机分配**：每次游戏自动分配卧底和平民身份

### 🎨 精致界面
- **深色主题**：紫色渐变 + 玻璃态设计，视觉享受
- **双端同步**：房主电脑 + 玩家手机实时联动
- **流畅动画**：平滑过渡，操作丝滑

### ⏱️ 智能功能
- **发言计时**：每人限时发言，避免拖沓
- **投票系统**：匿名投票，一键统计结果
- **自动轮转**：发言顺序自动提醒
- **房主管理**：一键控制游戏进程

## 🎲 游戏规则简介

1. **身份分配**：系统随机分配「卧底」和「平民」身份
2. **词语发放**：
   - 平民：得到相同词语（如「苹果」）
   - 卧底：得到相似词语（如「香蕉」）
3. **轮流发言**：每人描述自己的词语，但不能直接说出
4. **投票淘汰**：每轮结束后投票选出疑似卧底
5. **胜利条件**：
   - 平民胜利：找出所有卧底
   - 卧底胜利：存活到只剩 1-2 人

## 💡 游戏技巧

### 🎯 平民策略
- 观察他人描述，寻找不一致
- 不要过于直接，避免暴露
- 联合其他平民，共同推理

### 🕵️ 卧底策略
- 模仿平民描述，融入群体
- 故意模糊表述，制造混乱
- 关键时刻反咬一口
